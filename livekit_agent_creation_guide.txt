# LiveKit Voice Agent Creation Guide

## Overview
This guide provides instructions for creating voice agents using LiveKit based on the Quitanda example. Follow this structure to create conversational agents that can answer calls, process information, and interact with external services.

## 2. State Management

### Cache Implementation
```python
# Cache for frequently accessed data
DATA_CACHE = {"data": None, "expires_at": None}
CACHE_TTL = 300  # seconds (5 minutes)

def get_cached_or_compute(cache_dict, compute_fn, *args, **kwargs):
    """Returns cached data if valid, or computes and updates cache."""
    now = datetime.now(TZ)
    if cache_dict["data"] and cache_dict["expires_at"] and now < cache_dict["expires_at"]:
        log.debug("Using cached data (valid until %s)", cache_dict["expires_at"])
        return cache_dict["data"]
    
    # Compute new data
    result = compute_fn(*args, **kwargs)
    
    # Update cache
    cache_dict["data"] = result
    cache_dict["expires_at"] = now + timedelta(seconds=CACHE_TTL)
    log.debug("Cache updated, valid until %s", cache_dict["expires_at"])
    
    return result
```

## 3. External Data Fetching

```python
async def fetch_external_data() -> None:
    """Load external data with resilience to failures."""
    try:
        async with aiohttp.ClientSession(timeout=aiohttp.ClientTimeout(total=15)) as sess:
            try:
                async with sess.get("YOUR_API_ENDPOINT", timeout=8) as resp:
                    if resp.status != 200:
                        log.error(f"Error fetching data: HTTP {resp.status}")
                        return
                    
                    try:
                        data = await resp.json(content_type=None)
                        # Process data
                        log.info("External data loaded successfully")
                    except json.JSONDecodeError as e:
                        log.error(f"Error processing JSON: {str(e)}")
            
            except asyncio.CancelledError:
                log.warning("Data loading cancelled")
    
    except Exception as e:
        log.error(f"Critical error loading data: {str(e)}")
```

## 6. Agent System Prompt

```python
def build_system_prompt() -> str:
    """Generates system prompt with relevant data."""
    now = datetime.now(TZ)
    current_time = now.strftime("%H:%M")
    current_day = now.strftime("%A")

    # Include any dynamic information
    status_info = "Current status information"
    
    return (
        f"CURRENT TIME: {current_time} ({current_day})\n"
        f"STATUS: {status_info}\n\n"
        f"{LANGUAGE_NUDGE}\n\n"
        f"{LANGUAGE_EXAMPLES}\n\n"
        "ADDITIONAL GUIDELINES:\n"
```

## 7. Agent Entrypoint and Session

```python
async def entrypoint(ctx: JobContext):
    # Record call start for metrics
    mark("start")

    # Load any necessary data
    await fetch_external_data()
    
    # Configure language model
    llm = openai.realtime.RealtimeModel(
        model="gpt-4o-realtime-preview", 
        voice="alloy",  # Choose appropriate voice
        temperature=0.5,
        turn_detection=TurnDetection(
            type="semantic_vad", 
            eagerness="auto",
            create_response=True, 
            interrupt_response=True)
    )

    # Define agent tools
    tools = [get_information, process_request]

    # Initialize agent with system prompt
    agent = Agent(instructions=build_system_prompt(), tools=tools)
    session = AgentSession(llm=llm)

    # Connect and start session
    await ctx.connect()
    await session.start(agent, room=ctx.room)

    # Initial greeting or instructions
    initial_greeting = """
    Your initial greeting and instructions for the model go here.
    Include any specific voice/tone guidance.
    """
    
    await session.generate_reply(instructions=initial_greeting)
```

## 8. Application Runner

```python
if __name__ == "__main__":
```

## 10. Best Practices

1. **Error Handling**: Implement try-except blocks for all external calls and data processing
2. **Caching**: Cache frequently accessed data to reduce latency and API calls
3. **Logging**: Use detailed logging for debugging and monitoring
4. **Metrics**: Track key events with timestamps to measure performance
5. **Timeout Management**: Set timeouts for all external API calls
6. **Graceful Degradation**: Provide fallback responses when services are unavailable
7. **Language Customization**: Use language nudges and examples to guide model behavior
8. **Prompt Engineering**: Craft clear system prompts with specific instructions

## Troubleshooting Common Issues

1. **Connection Problems**: Verify LiveKit credentials and network connectivity
2. **Model API Errors**: Check API key validity and usage quotas
3. **Tool Function Failures**: Debug external API connections
4. **Voice Quality Issues**: Adjust voice settings and language nudges
5. **Conversation Flow Problems**: Refine system prompt and instructions

## Conclusion

Follow this guide to create robust, reliable voice agents with LiveKit. Customize the components to fit your specific use case while maintaining the core structure for stability and performance.
